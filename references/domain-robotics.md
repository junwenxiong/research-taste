# 具身智能与物理机器人专属红队闸门（可插拔领域模块）

> 当研究方向涉及真实机器人、物理仿真交互、VLA / 具身大模型或硬件传感时，在阶段 2 扫雷与阶段 4 资源落地中加载本模块。

## 1. 物理机器人五项防自欺红队尺

1. **物理量与代理指标真伪核查**
   - 严查所提代理信号是否混入无关物理项（例如关节机械功率 $|\tau \cdot \dot q|$ 混有重力做功、惯性项与减速器摩擦，不能直接冒充纯接触耗散；无独立测力台/力传感器时，减速器静摩擦与运动漂移必须实测标定而非凭假设）。
2. **严禁同仿真引擎既当裁判又当真值**
   - 若规划器、排序器或奖励模型与评估环境使用同一物理引擎和同一接触模型族，即便注入观测噪声仍会严重高估方法优势；必须留出未见接触/材质族，并用**第二物理引擎**或真实硬件交叉验证。
3. **隐藏物理成本全额记账**
   - 凡涉及主动探索、反事实筛选、投机回滚、多臂互等或失败复位的方案，必须把**筛查试验次数、制动与物理回滚墙钟、卡死人工复位耗时**全额计入总时间或总采样预算，严禁免费白嫖前置试验。
4. **因果与隐状态偷读封堵**
   - 宣称“在未知隐状态下不靠辨识即可执行成功”的机制，评测代码必须强制：**进程级隔离**（固定观测下重随机化隐藏物理参数，规划输出哈希必须不变）、**动作后观测遮断**与**执行前锁定单一后续动作**，并同步报告初态反推准确率作负对照。
5. **统计功效与基础设施倒挂核查**
   - 真机小样本（如 20 次试验、50% 成功率）95% 置信区间宽达约 ±22 个百分点，严禁把真机随机涨落当梯度，梯度探索优先在可控仿真用配对种子完成；
   - 检查方案依赖的辅助基础设施（如自动摆出临界难例的对抗机械臂、自动无损复位器、高精度在线 Real-to-Sim 重建）是否本身是比原任务更难的未解问题。

## 2. 分层系统中基础大模型与底层控制的职责红线

当研究采用“前沿多模态大模型 / VLM（慢决策）+ 参数化技能或轻量本地策略（快执行）+ 安全门控”架构时，必须严格划清职责边界：

| 职责类别 | 该由基础大模型负责（开放场景语义，固定规则写不全） | 严禁交由基础大模型负责（一做即导致物理不可靠或审稿拒稿） |
|---|---|---|
| **不确定性与物理建模** | 从视觉与任务描述中提出当前新场景**哪些隐变量重要**（质心、摩擦区间、铰接、隐藏支撑）及其离散候选结构；提出语义约束与禁止项（易碎、含液禁倾、禁推向桌沿） | 从单帧图像凭空编造连续摩擦/刚度数值；直接输出推动距离与施力大小；估算定量失败概率或风险分位数；替代物理求解器判定可行性 |
| **执行、安全与验证** | 根据新观测做高层条件分支、输出可校验的结构化任务意图；标注**语义不可逆属性**（只能收紧、不能放宽底层安全门）；用语义定义任务等价目标集 | 进入任何高频实时闭环（<1 s）；直接判定接触是否发生或已恢复到等价集；决定制动时机；绕过底层物理校验放行不可逆动作 |

## 3. 采用闭源前沿 API 时的顶会防拒稿三件套

若主线依赖闭源前沿模型 API（而非从零训练端到端 VLA / 视频世界模型），实验设计必须补齐以下三项才具备顶会可复现性与审稿防御力：
1. **多模型 + 本地固定权重复现**：主实验至少覆盖 **≥2 个前沿 API + ≥1 个本地固定权重开源 VLM**，并全程保存输入输出日志支持离线确定性重放。
2. **去大模型消融对照**：必须对比“不调用大模型的固定规则 / 纯几何基线”，证明大模型在开放场景语义结构上的真实增益，而非靠更强底座掩盖算法缺陷。
3. **算法与 Prompt 解耦**：全部定量搜索、风险评估与安全放行留在确定性或可学习底层模块中，使方法章节与核心结论不依赖特定提示词或单一模型版本。
