# 开源研究品味方法论拆解与实操工具箱

> 蒸馏自 5 套开源研究品味 Skill（`xie-saining-research-taste-skills`、`pengsida-learning-research-skills`、`Orchestra 21-research-ideation`、`Punktheory research-idea-and-battle`、`paper-reader-heilmeier`）与 Google DeepMind `AI Co-Scientist` (`arXiv:2502.18864`) 的跨模型源码拆解与实盘对照。

## 1. 六大流派分工与防越权边界

| 流派 | 在本流程中的唯一职责 | 严禁越权做的事（实测盲区） |
|---|---|---|
| **谢赛宁（Saining Xie）** | ① 反流行未检共识（Consensus Check）；② 把 Impact 改写成 Understanding；③ 跑前写 Prediction 找梯度 | 不要只产出“诊断漂亮但没人改做法”的分析型平庸；不可忽视小样本真机统计功效 |
| **彭思达（Sida Peng）** | ① 四情况引文闸门（前后各走一跳）硬止损；② Failure Case → Core Challenge 树；③ **强制列 1 条故意保守的 A+B 下界** | 不要陷入“多模块 Pipeline 串联 = 创新”崇拜；对实验可复现性差的近邻加折扣而非盲杀 |
| **Orchestra（Boden + TRIZ）** | ① 解除隐藏约束；② **物理 TRIZ**（时间/空间/条件分离与反转）；③ 结构级跨领域映射（强制写明**断裂点**） | 严禁轻信未经反例压测的修辞类比；不要拿 Two-Sentence Pitch 当淘汰筛子（大模型都能写漂亮） |
| **Punktheory（idea-battle）** | ① 必须配**实时联网搜索**扫研究坟场（旧死因今天是否仍在）；② Timing 三分（太早 / 正好 / 太晚） | 严禁以“稳妥可发”为立项目标；不要在发散前先读综述锚定共识 |
| **DARPA Heilmeier** | ① **Q1 零黑话一句话**作终审照妖镜；② 补回 DARPA 原版“需要多久”与“中期/期末考试判据” | 不是点子生成器，仅用于终审压缩、剥离黑话与立项签单 |
| **AI Co-Scientist** | ① **异构多模型真盲评**全轮转配对 + 随机赛序 Elo；② **Meta-Review 抽象升维**（删包装、留单一原语） | 严禁用单模型角色扮演多个评委替代真异构模型（无法消除 `+32 ~ +46` Elo 同源风格自偏好） |

## 2. 阶段 1 发散与检视速查工具

### A. 谢赛宁 7 Checks（检验问题层级）
1. **Problem**：核心问题是否清晰，谁定义它，当前表述隐藏了什么？
2. **Understanding**：若成功，具体让谁多懂了一件此前不清楚的事？
3. **Reality**：问题是否来自真实数据、物理约束或明确失败模式，而非闭门造车？
4. **Gradient**：什么最小实验能在几天内给出正或负的清晰信号（平坦无变化是最坏信号）？
5. **Prediction**：跑实验前是否已写死预期结果及对应决策分支？
6. **Taste**：外部读者能否清晰重建每一步关键取舍的因果链？
7. **Consensus**：具体挑战了哪条行业默认继承却未经验证的流行假设？

### B. 彭思达四情况引文闸门（沿最强近邻引文前后各走一跳）

| 情况 | 判定条件 | 强制结论 |
|---|---|---|
| **情况 1** | 相同输入输出任务已有不错方案，仅局部指标不够好 | **硬止损换题**（创新空间趋近于 0） |
| **情况 2** | 任务形式略变，但跨多领域已有同内核通用解法可直接迁移 | **硬止损换题** |
| **情况 3** | 存在跨任务通用的真实 Failure Case，拆解后现有内核无法靠 `A+B` 解决 | **放行** → 列 ≥3 条候选方案（**强制含 1 条故意保守的 `A+B` 下界**） |
| **情况 4** | 新问题定义或新物理/系统原语，现有范式无法表达 | **重点放行** → 同步核查 Timing 与 10× 缩放压测 |

### C. Orchestra 8 个破局算子（发散期强制选 ≥2 个）
1. **隐藏约束解除**：点名所有人都当成理所当然、但其实可以打破的隐含前提。
2. **物理 TRIZ 分离**：存在物理矛盾时，按**时间分离 / 空间分离 / 条件分离 / 整体-部分分离**拆解。
3. **目标/过程反转**：把“顺推”改“逆推”、把“先测后干”改“不测直接改状态”、把“先采成功”改“先采高价值失败”。
4. **抽象阶梯升降**：向上问“这一类机制的统一原语是什么”，向下问“删掉所有包装后最小可证伪单元是什么”。
5. **跨领域结构映射**：借用另一学科的成熟数学/控制结构，**必须同步写出该映射在目标领域的 1 个物理或数学断裂点**。
6. **双域交叉**：把两个不交集的真约束放到同一预算公式里联合优化。
7. **邻近可能**：锁定近 6 个月刚成熟的新能力边界（算力/模型/仿真），问“一年前做不到、今天刚好能做的是什么”。
8. **矛盾并存**：拒绝折中平均，把两个互斥需求统一为同一状态变量的不同区间。

### D. 坟场扫雷与 DARPA Heilmeier 终审补全
- **研究坟场三问**：① 过去 5 年谁试过类似路线？② 当年真正卡死在算力、数据、硬件还是数学原理？③ 今天这个死因是否已被客观消除？
- **Heilmeier 终审必答**：① 零黑话一句话（禁缩写、禁比喻）；② 现有做法的硬上限在哪；③ 新机制究竟删掉了什么、改了哪一步；④ 若成功谁会改变做法；⑤ 最大风险与 3 天/1 周中期考试判据（量化通过线与硬止损线）。
